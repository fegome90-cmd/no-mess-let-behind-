# No Mess Left Behind

Plugin de Obsidian para administrar la gobernanza de un vault mediante herramientas existentes, con mantenimiento reducido.

## Estado inicial

Este commit solo establece la raíz Git de un repositorio vacío. No contiene implementación ni una versión instalable. La base funcional y la adopción de la Constitución de Código Agéntico se preparan en una rama de trabajo para revisión; no se integran automáticamente en `main`.

## Alcance autorizado

Configurar este repositorio como plugin de Obsidian, reutilizando Kit Fundador LEGO, la constitución agéntica y skills pertinentes de `my-skills`. No instalar en vaults existentes, modificar configuraciones globales, publicar una release ni fusionar cambios sin autorización adicional.

## Principios

- Reutilizar motores externos; no mantener traductores universales ni linters propios.
- Separar configuración declarada, ejecución observada y bloqueo comprobado.
- Preservar fuentes, notas y hooks existentes; diagnóstico sin autoescritura.
- Mantener trazabilidad de dependencias, pruebas y limitaciones.
